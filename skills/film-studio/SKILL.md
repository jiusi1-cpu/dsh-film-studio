# 短视频工坊（film-studio）

这是一条已经跑通的成品流程。**照着做，不要另起一套**；用户不需要在音色上做选择。

## 依赖：先看有什么

| 依赖 | 有的话 | 没有的话 |
|---|---|---|
| `film_voice` 工具（插件） | 直接调用 | 跑 `python scripts/filmvoice.py --job job.json`，参数一样 |
| `flash-motion` 技能（`fm.py`） | 用 `film_new` 或 `fm.py new` 生成骨架 | 手写 HTML 时必须遵守文末「硬规矩」，并且用 Playwright 逐帧截图 + ffmpeg 合成 |
| 阿里云百炼 Key | `ALIYUN_BAILIAN_API_KEY` 环境变量或插件配置 | 没有 Key 就先出无声版，交付时说明 |

配音只要有 Key 就能单独用，不依赖 flash-motion。

## 出问题先跑 `film_doctor`

工具"看不到"、"一调用就报错"、怀疑装坏了，**先跑 `film_doctor`**（不用参数）。它一次看清：代码从哪加载、版本对不对、两个技能在不在、python 能不能用、密钥配没配、工作区可不可写，末尾给一句结论。

| 结论 | 怎么办 |
|---|---|
| 技能缺失 / 需更新 | 重启一次桌面端，插件会自动重装（先暂存再替换，失败不会把原有技能弄丢） |
| python 不可用 | 把插件配置的 `pythonPath` 设成 python.exe 绝对路径 |
| 密钥未配置 | 配音会失败，其余功能可用；在插件配置里填 apiKey |
| 工作区不可写 | 换一个可写目录，或检查目录权限 |

## 路径规则（踩过坑，务必遵守）

所有工具的路径参数（`projectDir`、`outDir`、`name`）**相对路径一律按工作区解析**，也可以直接给绝对路径。

- ✅ `film_check projectDir="my-film"` → `<工作区>/my-film`
- ✅ `film_check projectDir="C:/Users/xxx/proj/film"` → 原样使用
- ❌ 不要假设相对路径会落到工程本身里；写 `out/voice` 就是 `<工作区>/out/voice`

如果返回「工程目录不存在」，八成是相对路径写错了，换绝对路径最快。

## 0. 先确认三件事

1. 工程目录：用户的工作区下新建 `<项目名>/`，或沿用已有工程。
2. 成片参数：默认 **16:9 / 1920×1080 / 30fps**，时长由配音长度决定（不硬凑）。
3. 内容来源：屏幕上的每个数字都要能指出来源；没有来源就不写数字。

## 1. 起步：生成骨架（不要手写 HTML 从头开始）

```
fm.py new <项目目录> --style paper-press --ratio 16:9 --title "标题"
```

工具形式：先 `film_check` 确认技能装好，再在项目目录跑渲染。骨架里有 4 个场景（hook / point / list / outro）、相机缓推、颗粒暗角，已经是能用的画面；**你只需要改文案和加场景**。

## 2. 配音：调 `film_voice`，音色不要问用户

- **默认音色 `xuxiaoqiao_v3.1`（小俏），语速 0.92**，不用问、不用选。
- 备选（只有用户明确要求时才换）：`qiaoxiaojiao_v3.1`（小娇，更软）、`yunhuanhuan_v3.1`（欢欢，更元气）。
- 一定要传 `sceneGroups`，把句子映射到场景，`timeline.js` 才会按配音重排画面。
- 拿到 `voice.wav` / `timings.json` / `timeline.js` 后，工程里 `index.html` 要改成读 `window.TL`（骨架已预留约定：`const TL = window.TL`）。
- 想要更慢更稳就把 `rate` 调到 0.85；别用 1.0 以上，会赶。

## 3. 什么时候调生图（`workbench-image-generation` / `generate_image`）

**要生图的三种情况**，其余一律用排版和图形解决：

1. 需要**角色/吉祥物**（有人设的形象、表情、动作）；
2. 需要**实拍替代物**（产品照、场景照、人物照）而手上没有素材；
3. 需要**手绘/插画风格**的整屏背景承载情绪。

不需要生图的情况：数字、流程、对比、时间线、引用、标题卡——这些用文字和图形更快更准。

生图规范：

- 统一底色（例如 `#FFFBF2`），方便和页面无缝拼接；
- 同一角色多次出现时，**带上一张参考图**（`references`）保持一致性；
- 生成后立刻 `read_image` 看一眼，糊了、文字错了、比例歪了就重生成，别把坏图放进片子。

## 4. 质检与渲染（顺序不能颠倒）

```
fm.py check index.html        # 必须 0 错误
fm.py sheet index.html        # 联系表，看图自查 2 轮
fm.py render index.html --mblur 2 --workers 3 --out out/film.mp4 --force
```

- `film_check` 有错误就别渲染，画面压字、字号过小、超出版面都会被它抓到。
- 看联系表时重点查：一屏是不是只有一个焦点、文字有没有被裁、数字有没有被遮挡。
- 渲染 1080p 大约每 100 帧 30 秒，整片 3–12 分钟，属正常。

## 5. 交付

`present` 成片 + `open_project_files` 打开；说明时长、体积、做过哪些检查，**没有真人试听就明说**。

## 硬规矩

- 画面是 `seek(t)` 纯函数：不准用 `Math.random` / `Date.now` / `requestAnimationFrame` / CSS 动画 / SMIL。
- 主标题 ≥ 86px@1080p；正文 ≥ 32px；一屏一个焦点。
- 除最后 1 秒外，不要连续 1.2 秒画面完全静止。
- 每 1.5–2.5 秒要有一个新信息点。
- 时长不要写死在代码里，从 `window.TL.dur` 读。
